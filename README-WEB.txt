Rime — веб-версия
=================

Полноценный мессенджер в браузере: тот же интерфейс, что в EXE/APK,
но открывается по адресу в браузере на ПК, телефоне или планшете.
Сервер на Python, база SQLite, никаких pip-пакетов устанавливать не нужно
(только стандартная библиотека Python 3.10+).

СОСТАВ
------
server.py            — сервер (API + раздача сайта).
index.html           — весь интерфейс.
vendor/lottie.min.js — проигрыватель TGS-подарков.
cards/ case/ gift/ data/ — карточки, кейсы, подарки, фоны.
manifest.webmanifest, sw.js, иконки — установка как приложение (PWA).
server_start.bat     — запуск на Windows.
server_start.sh      — запуск на Linux/macOS.
Dockerfile, Procfile — для хостинга/VPS.
README-WEB.txt       — этот файл.

БЫСТРЫЙ ЗАПУСК НА ПК
--------------------
Windows: двойной клик по server_start.bat.
Linux/macOS:
    cd Rime-web
    python3 server.py
Затем открой http://localhost:8080

Первый зарегистрированный аккаунт автоматически получает статус владельца.
Данные (rime.db, uploads, private) создаются рядом с server.py.
Бэкап — скопировать rime.db. Перенос данных с ПК-версии — скопировать
rime.db (и папки uploads/private, если нужны аватарки и файлы) сюда.

ПОРТ
----
    python server.py --port 9000
или переменная окружения PORT=9000 (RIME_PORT тоже работает).
Если порт занят, сервер сам возьмёт следующий свободный и напишет адрес
в консоли.

ДОСТУП С ТЕЛЕФОНА В ТОЙ ЖЕ WI-FI
--------------------------------
1. На ПК: ipconfig → IPv4 (например 192.168.1.42).
2. Разреши Python/сервер в брандмауэре Windows (частная сеть).
3. На телефоне: http://192.168.1.42:8080

РАЗМЕЩЕНИЕ В ИНТЕРНЕТЕ (VPS / хостинг с Python)
-----------------------------------------------
Нужен хостинг, где можно запускать Python-процесс (VPS, Render, Railway,
Docker и т.п.). Обычный статический хостинг (GitHub Pages, Netlify static)
НЕ подойдёт: приложению нужен сервер и база данных.

Вариант Docker:
    docker build -t rime-web .
    docker run -d -p 8080:8080 --name rime rime-web
Чтобы база и загрузки сохранялись между перезапусками:
    docker run -d -p 8080:8080 --name rime \
        -v "$PWD/rime.db:/app/rime.db" -v rime-uploads:/app/uploads rime-web
(файл rime.db должен существовать заранее — запусти сервер один раз локально).

Render/Railway: залей папку в репозиторий, Procfile уже содержит
    web: python server.py
Порт берётся из переменной PORT автоматически.

HTTPS и PWA: service worker и «Установить приложение» в Chrome работают
только на HTTPS (или на localhost). На VPS поставь nginx/Caddy с HTTPS
перед сервером. Без HTTPS сайт полностью работает, просто без установки
как приложение.

ОСОБЕННОСТЬ ХОСТИНГА
--------------------
На бесплатных тарифах с «эфемерным диском» rime.db может обнуляться при
перезапуске контейнера. Для постоянных данных используй VPS или платный
диск/volume.

ВОЗМОЖНОСТИ
-----------
- Регистрация/вход, друзья, личные и групповые чаты.
- Подарки (включая TGS-анимации), карточки, кейсы «Все подарки»,
  крафт, ежедневный бонус, рубины.
- Маркет: продажа/покупка карточек, подарков и игр; загрузка своих игр.
- Музыка SoundCloud/Spotify в профиле.
- Бот Codex Clyd AVI 1.0.
- Админ-панель (владелец), заявки на бейджи, организации.
- Тёмная «малиновая» и светлая «аврора» темы.
